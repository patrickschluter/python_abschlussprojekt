# IT-Support und Systemadmin Diagnose-Tool

## Beschreibung

Dieses Projekt ist ein Python-Konsolenprogramm für den IT-Support und die Systemadministration.

Das Programm kann Tickets verwalten, CSV-Dateien auslesen, Logdateien durchsuchen, Ordner analysieren und einen Systemreport erstellen.

## Funktionen

Das Programm bietet folgende Funktionen:

1. Neues Ticket erstellen
2. Bestehende Tickets anzeigen
3. Benutzerliste anzeigen
4. Inventarliste anzeigen
5. Logdatei durchsuchen
6. Ordner analysieren
7. Systemreport erstellen
8. Programm beenden
